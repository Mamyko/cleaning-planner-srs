# Планировщик уборки (Cleaning Planner)

Репозиторий содержит техническое задание (SRS) для приложения «Планировщик уборки»,
разработанного в рамках лабораторной работы №1 по дисциплине
«Разработка и управление требованиями к программному обеспечению».

## Состав артефактов

- **Wiki → [Техническое задание](../../wiki/Техническое-задание)** — основной документ с требованиями.
- **Issues** — детализированные требования в виде User Stories с критериями приёмки.

## Краткое описание приложения

«Планировщик уборки» — приложение для ведения чек-листа регулярных и разовых дел по дому.
Позволяет создавать задачи уборки с периодичностью, отмечать выполнение, получать
напоминания и отслеживать прогресс.
